# ServiceAutoInjector

ServiceAutoInjector is a .NET 10 library that automates Dependency Injection. By scanning assemblies for marker interfaces, it instantly registers classes as transient, scoped, or singleton services. Eliminate boilerplate code, streamline startup, and easily maintain clean architecture in your .NET projects.

## Installation

Install the package via the .NET CLI:

```
dotnet add package kmaraszkiewicz86.ServiceAutoInjector
```
